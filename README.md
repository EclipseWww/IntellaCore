# AI 辅助教育平台

面向信息科技课堂的学习平台，提供学生、教师和管理员角色，支持课程与课时、作业提交、AI 问答、测验、Office 作业评分及教学资源迁移。

前端使用 React、Ant Design；后端使用 Node.js、Express 和 Mongoose，数据存储于 MongoDB，支持 Docker 部署。

## 开始使用

- 新部署：[部署指南](docs/DEPLOYMENT.md)。
- 已有实例升级：[更新与回退](docs/DEPLOYMENT.md)。
- 开发和贡献：[贡献指南](CONTRIBUTING.md)。

首次运行访问网站完成管理员初始化。管理员在系统管理中配置 AI 服务和学生退出密码。学生退出密码允许空值与短密码；空值须明确保存才生效。

## 公开发布与授权

环境文件、学生资料、作业、日志、备份和维护密钥不得提交。将仓库改为 public 会公开已有 Git 历史，修改当前文件不会移除旧提交里的凭据；发布前按安全说明审查历史并轮换曾暴露的凭据。

当前尚未声明项目整体开源许可证。公开可见不等于已授予开源使用许可；项目所有者需确认整体许可证，并保留第三方游戏、字体及依赖各自的授权文件。
