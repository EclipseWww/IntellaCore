📖 游戏说明

🎮 基本操作

使用 ← → 或 A D 或鼠标移动挡板
按 空格 或点击鼠标发射球
按 P 暂停/继续游戏

🎯 游戏目标

用球击碎所有砖块，通过5个关卡。球掉落会失去生命，3条命用完游戏结束。

✨ 特殊机制

• 击碎砖块有10%概率分裂出更多球（黄色）
• 击碎砖块有15%概率掉落道具
• 只有所有球都掉落才会失去生命

🎁 道具说明

  • 📏加宽挡板挡板变宽，持续8秒
  • 📐缩小挡板挡板变窄，持续8秒
  • 🔫激光按空格发射激光，持续8秒
  • 🧲粘性挡板球会粘在挡板上，持续8秒
  • 🛡️安全网底部出现保护网，可救一次球
  • ⚡加速球所有球速度加快
  • 🐢减速球所有球速度减慢

💡 小技巧

• 用挡板边缘击球可以改变角度
• 多球时注意不要让最后一个球掉落
• 调节速度滑块可以改变游戏节奏
